# Проект "Поиск вакансий через сервис HH"

## Описание:

Курсовой проект созданный для обучения языку python

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/ZloyKINDER/integration_hh.git
```

## Реализованный функционал:

1. Подключение к API сервиса HeadHunter для получения вакансий.

2. Работа с вакансиями, описание, требования, фильтрация и т.д.

3. Сохранение информации в JSON.


## Реализованны модули с тестированием:

1. test_utils - Тестирование для модуля utils.

2. test_api - Тестирование для модуля api.

3. test_vacancy- Тестировани для модуля vacancy.

4. test_storage- Тестировани для модуля storage.
